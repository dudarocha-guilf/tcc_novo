# Letrika

Projeto educacional em HTML, CSS, JavaScript, Node.js, Express e MySQL.

## Estrutura do projeto

- `letrika/database/` - Scripts SQL e banco de dados
- `letrika/backend/` - API REST em Node.js
- `letrika/frontend/` - Interface web em HTML, CSS e JavaScript

## Etapa 1 concluída

Esta etapa cria a estrutura inicial do projeto e o banco de dados MySQL.

### Próxima etapa

A próxima etapa será a criação do backend, incluindo:
- conexão com o MySQL
- arquivo `.env`
- servidor Express
- rota de cadastro
- testes com Postman ou Insomnia
